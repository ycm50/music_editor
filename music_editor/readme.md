# RCP 简谱编辑器 (C++ 核心)

基于简谱的音乐编辑和播放工具。核心是纯 C++20 库（无 Qt 依赖），桌面端与安卓端共用同一份源码完成**解析 → 物理合成 → WAV 编码**。

---

## 项目结构

```
music_editor/
├── CMakeLists.txt        # 根构建文件
├── core/                 # 共享库（纯 C++20，无需 Qt；桌面端/安卓端共用）
│   ├── note_parser.h/.cpp  # RCP 解析: 音符/元数据/物理参数/乐理校验
│   ├── tone_gen.h/.cpp     # 物理合成 + 33 种乐器预设 + 混响 + 体检指标
│   ├── note_builder.h/.cpp # 插入面板的 token/@acoustic 构造器（两端共用）
│   ├── ai_prompt.h/.cpp    # AI 系统提示词 + 可自检的示例乐谱（两端共用）
│   └── wav_writer.h/.cpp   # WAV 写入 (16/24-bit PCM + TPDF dither)
├── ../tools/             # 自检工具（test_syntax / test_physics / check_prompt）
├── player/               # 音乐播放器（需 Qt6::Multimedia）
├── save/                 # RCP→WAV + --analyze 体检（纯 C++，无 Qt）
├── ui/                   # GUI 编辑器（需 Qt6::Widgets）
│   ├── mainwindow.cpp      # 主窗口（编辑框/播放/导出/AI 生成）
│   └── insertpage.cpp      # 插入面板（勾选+参数插入音符 / 乐器预设）
├── 1.rcp / twinkle.rcp   # 乐谱数据文件
├── run_player.bat        # 播放器启动脚本（Windows）
└── run_ui.bat            # GUI 启动脚本（Windows）
```

## 依赖

- **编译器**: C++20 (GCC/MinGW 13+ / MSVC 2022+)
- **构建工具**: CMake ≥ 3.16, Ninja 或 MinGW Makefiles
- **Qt**: Qt 6.x (推荐) 或 Qt 5.15+
  - `player`: 需要 `Qt6::Multimedia` 模块
  - `ui`: 需要 `Qt6::Widgets` 模块
  - `save` 和 `core`: **不依赖 Qt**

### Windows 特殊说明

`player` 和 `ui` 依赖 Qt DLL。编译后运行：

```bash
# 方法一：使用启动脚本（自动设置路径）
run_player.bat 1.rcp
run_ui.bat

# 方法二：手动设置 PATH
set PATH=A:\msys64\ucrt64\bin;%CD%\build\player;%PATH%
build\player\player.exe 1.rcp
```

> `ui` 为 GUI 子系统（`WIN32_EXECUTABLE`），启动不弹终端窗口；它会自动在同目录或 `../` 下查找 `player.exe` / `save.exe`（发布包为同目录平铺）。

> **闪退排查**：`player` / `ui` 是动态链接 Qt 的，缺少 Qt DLL 时会立刻闪退。`run_ui.bat` / `run_player.bat` 已内置 Qt6 `bin` 目录自动探测（先看 `PATH` 里的 `qmake6.exe`，再依次试 `A:\msys64\ucrt64\bin`、`A:\msys2\ucrt64\bin`、`A:\msys64\mingw64\bin`、`C:\msys64\...`、`A:\Qt\6.*\mingw_64\bin`），并会打印 `[run_ui] Qt6 found at: ...`。若 Qt 装在别处，编辑脚本设 `set "QTBIN=你的Qt\bin"` 即可。手动验证：
> ```bat
> set PATH=A:\msys64\ucrt64\bin;%CD%\build\ui;%PATH%
> build\ui\ui.exe
> ```

> ⚠ **构建路径不要含中文**：Qt 的 `moc` 在非 ASCII 路径下无法创建输出文件。若源码目录含中文，先建 ASCII 目录联接再构建：
> `mklink /J A:\tmp\me-boot "A:\你的路径\music_editor"`

# RCP 文件格式

## 整体结构

```
# ── 注释以 "# " 开头 (井号后必须跟空格, 以免与升号 #4 冲突) ──
@ref A4=440          # 参考音高
@bpm 96              # 速度
@beat 0.625          # 标准拍长 (一个四分音符的秒数) = 60/BPM
@meter 4/4           # 拍号 (仅用于小节对齐校验)
@timbre harp         # 乐器
@voice 1             # 声部 1
6.04!f 7.04 1.+04 2.+04      # 每行 = 1 小节
@voice 2             # 声部 2 (独立时间轴, 与声部 1 纵向叠加)
6.-02 [6.-02+1.02]_[6.-02+1.02]
```

行序无关，`@` 元数据行可任意顺序出现。**兼容旧格式**：第 1 行若写 `BPM,基准频率,标准拍长`（如 `120,261.63,0.5`）照旧可用；第 2 行若为"逗号分隔非负数字"（至少两个）且不是合法音符行，视为谐波振幅表；第 3 行若可被持续比例解析器接受，视为持续比例行（会记一条 deprecated 提示）。

### 解析容错与严格模式

- **`parse_rcp`（默认，用于播放/导出）：容错**。单个 token 写错时记入 `warnings`（含行号与原因）并跳过它，其余音符照常渲染 —— 一个笔误不该让几百行的谱整体打不开。
- **`parse_rcp_strict`（用于"检查乐谱"/自动化校验）：严格**。任何 token 语法错误直接抛 `std::invalid_argument`，消息形如 `第 3 行 token "5.00:5": 拍长分母必须 >= 1 (...)`。

UI 的校验按钮走严格模式，方便定位错误；实际播放走容错模式，并在状态栏显示跳过了哪些 token。

## 头部参数

| 写法 | 含义 |
|---|---|
| `BPM,基准频率,标准拍长` | 旧写法（三值逗号分隔，会检查 BPM 与拍长是否自洽） |
| `@bpm 96` / `@tempo 96` | 速度（仅信息，实际时值以拍长为准） |
| `@ref 261.63` | 1=do 的频率 |
| `@ref C4` / `@ref A4=440` / `@ref 1=C` | 等价的音名写法 |
| `@beat 0.625` | 标准拍长（四分音符秒数） |
| `@meter 4/4` / `3/4` / `6/8` | 拍号，用于 `--analyze` 的小节对齐校验 |
| `@timbre 名称` / `@instrument 名称` | 乐器（见下方乐器表） |
| `@acoustic 名称 k=v;...` | 自定义物理模型 |
| `@dyn mf=0.6,p=0.3` | 自定义力度映射（名称=线性振幅，覆盖内置 dB 表，也可新增名称） |
| `@voice N` | 声部标记，每个声部独立时间轴 |

## 音符语法

```
<音级>[变音].<八度><拍长分母>[附点][t|q][!力度][@音色][$物理覆盖][~|']
```

| 部分 | 取值 | 说明 |
|---|---|---|
| **音级** | `1`~`7` | do re mi fa sol la si |
| | `0` 或 `r` | 休止符（渲染为**真静音**，不占合成开销） |
| **变音** | `#` `b` `##` `bb` `n` | 可写在音级前或后：`#4` 与 `4#` 等价；`n` 为还原 |
| **八度** | `0` | 中音 |
| | `+` / `-`（可连写） | 高/低八度，范围 ±4：`++`=高两个八度，`--`=低两个八度 |
| **拍长分母** | `4` | 四分音符（1 拍） |
| | `2` / `1` / `8` / `16` / `32` | 二分 / 全 / 八分 / 十六分 / 三十二分 |
| **附点** | 分母后加 `.` | 时值 ×1.5：`4.`=附点四分（1.5 拍）、`2.`=附点二分（3 拍） |
| **连音符** | 分母后加 `t` | 三连音（时值 ×2/3）：`4t` 三个音合起来 2 拍 |
| | 分母后加 `q` | 五连音（时值 ×4/5）：`4q` 五个音合起来 4 拍 |
| **力度** | `!ppp` `!pp` `!p` `!mp` `!mf` `!f` `!ff` `!fff` 或 `!0.42` | 依次为 −24/−16.5/−10.5/−6.9/−4.4/−2.2/0/+3 dB（可用 `@dyn` 覆盖），允许 0~4；**力度同时改变音色**（越重越亮越硬） |
| **物理覆盖** | `$dec=0.4/sus=0/atk=0.01/br=0.8/B=0.001/pos=0.125/tilt=6/damper=0.08/ring=5/n2=0.03/uni=3/detune=0.9/pan=-0.3` | 逐音覆盖乐器参数，多项用 `/` 分隔 |
| **演奏法** | `~` | 连奏（标记保留） |
| | `'` | 断奏（时值 ×0.5） |

**连音 `_`**：连接相邻的同音高音符，**时长相加且只起音一次**。

```
1.04_1.04              → 一个二分音符 (起音一次, 包络连续)
5.04_5.08_5.08         → 一个二分音符
[1.02+3.02]_[1.02+3.02] → 一个全音符的三度和弦 (两个音都只起音一次)
```

**和弦 `[...]`**：成员用 `+` 或 `,` 分隔（推荐 `,`，因为 `+` 与八度记号冲突），同一时刻纵向发声，成员时值自动统一到最长。和弦后面的**修饰符作用于整个和弦的每个成员**：

```
[1.04+3.04+5.04]         → C 大三和弦, 一拍
[6.04,1.+04,3.+04]       → Am 和弦 (推荐写法)
[1.02,3.02,5.02]!f       → 三个音同时强奏 (力度作用于整组)
[1.02,3.02]_[1.02,3.02]!pp  → 和弦连音成四拍, 整组弱奏
[1.04,3.04]$dec=0.3      → 整组衰减时间常数 0.3s
```

**多声部**：`@voice N` 之后的音符进入该声部，每个声部从时间 0 开始独立推进，最终纵向混合。

**完整示例**

```
3.+2        3 的高八度二分音符
#4.+8       升 4、高八度、八分音符
b7.-2       降 7、低八度、二分音符
0.04 / r.04 休止一拍 (真静音)
2.08.       附点八分音符
1.04t       三连音中的一个音
1.+4!ff     强奏
5.+2$dec=0.3/sus=0   该音衰减 0.3s、无稳态 (拨弦感)
```

## 物理乐器模型

`@acoustic` 用一组物理量描述一件乐器（取代旧的『逐倍频时间窗』写法）：

```
f_n     = n · f1 · √(1 + B(f1)·n²)              分音频率 (劲度 → 非谐性)
B(f1)   = B · (f1/261.63)^alpha                 B 随音高上升 (钢琴 1e-4 → 1e-1)
A_n(0)  = 频谱包络(n,f_n) · |sin(nπ·pos)| · 共鸣体(f_n) · 力度倾斜
τ_n     :  1/τ_n = 1/τ1 + n2·(n²−1)   或   τ_n = damp/n^exp
包络(t) = 起音(力度相关) + sus + (1−sus)·[(1−β)e^(−t/τ_fast) + β·e^(−t/τ)]
          t > 记谱时值 时再乘 e^(−(t−gate)/damper)   (制音器 → 齿毡阻尼)
发声长度 = 有制音器: 记谱时值 + 6.5·damper
           无制音器: 分音能量衰减到 −60 dB 的时间 (上限 ring)
起音噪声 = 用同一组分音做共振的『模态噪声』 (而非未滤波白噪)
f_n ≥ 0.49·fs 的分音不再生成                          抗混叠
```

| 键 | 单位 | 含义 | 典型值 |
|---|---|---|---|
| `B` | — | 非谐性 @C4 | 理想弦 0；吉他 1e-5；钢琴 2e-4；钟 3e-2 |
| `alpha` | — | B 随音高指数：B(f)=B·(f/261.63)^alpha | 钢琴 1.6 |
| `tilt` | dB/oct | 源频谱倾斜（给出后取代 `br` 的几何律） | 钢琴 6；长笛 5 |
| `br` | 0~1 | A_n(0)=br^(n−1)（未给 tilt 时生效，br=1 即平坦） | 0.3 ~ 0.9 |
| `damp` | 秒 | τ1（也可 `damp=τ1/exp`，或 `damp=τ1,τ2,…` 逐分音） | 钢琴 2.5；小提琴 0.6；长笛 0.4 |
| `n2` | — | 1/τ_n = 1/τ1 + n2·(n²−1)：高次分音额外阻尼 | 钢琴 0.02；吉他 0.04 |
| `beta` | 0~1 | 双指数余韵权重（钢琴『先快后慢』） | 钢琴 0.30 |
| `atk` | 秒 | 起音时间（平方上升） | 击弦 3ms；弓弦 55ms；气流 80ms |
| `sus` | 0~1 | 稳态电平 | 钢琴 0；小提琴 0.82；管风琴 1.0 |
| `damper` | 秒 | 制音器 τ（**0 = 无制音器，自由余音**） | 钢琴 0.09；钟/竖琴/八音盒 0 |
| `ring` | 秒 | 无制音器乐器的余音上限 | 钟 12；竖琴 9；锣 20 |
| `noise` / `nl` | 0~1 / 秒 | 起音噪声量与时长 | 吉他 0.35；长笛 0.30 |
| `pos` / `posp` | x/L / — | 激励点（拨/击弦位置）与 1/n^p 包络 | 钢琴 0.125；吉他 0.2；单簧管 0.5 |
| `body` | f:Q:dB,… | 共鸣体共振峰（音板/琴箱/管体） | 小提琴 275:6:6,450:8:5 |
| `hpf` | 频率:dB/oct | 低频滚降（音板尺寸造成的截止） | 钢琴 85:6 |
| `uni` / `detune` | 根 / 音分 | 同音弦组与弦间失谐（拍频闪烁） | 钢琴 3 / 0.9 |
| `vtilt` / `velatk` | dB/oct / 0~1 | 力度→音色（越轻越暗）与力度→起音 | 钢琴 5.0 / 0.45 |
| `floor` / `maxp` | — / 个 | 分音听阈裁剪与分音数上限 | 1e-4 / 96 |
| `phase` | coherent/random | 初相：相干（由 `pos` 决定 0/π）或随机 | coherent |
| `temp` / `stretch` | 律制 / 0~1 | 12tet/just/pyth；伸展调音（Railsback 曲线近似） | 12tet / 钢琴 1.0 |
| `table` | 比率:振幅:τ,… | 显式分音表（钟/马林巴/定音鼓等非谐波乐器） | 见 `bells` |
| `pan` / `panpitch` | -1~1 / 0~1 | 固定声像与声像随音高展开（钢琴键盘感） | 钢琴 panpitch 0.55 |
| `stereo` | 0~1 | 声像宽度（与 pan/panpitch 叠加，加宽立体声像） | 钟 0.35；小提琴 0.30 |

**四个关键点**：

1. `damp`/`damper` 都是**绝对秒数**，与音符写多长无关：记谱时值 = 按键/弓/气流时长，松键后按 `damper` 衰减；`damper=0` 的乐器会一直响到能量衰减 −60 dB（上限 `ring`）——**钟写 1 拍也会余音 12 秒**。
2. 分音数由 **f0 与可听带宽**决定：低音区分音多（C2 约 96 个），高音区分音少（C6 约 16 个）；旧版『固定 12 个分音』会把低音区低通到 800 Hz。
3. 频谱包络以**频率**为自变量（tilt + 共鸣体共振峰 + 激励点零点），所以同一件乐器在不同音区音色不同（实测重心/基频：C3 6.2 → C6 3.1）。
4. 力度不只改音量：越重越亮、起音越硬、击弦噪声越大（实测 !pp 与 !ff 同音高重心差约 30%）。

几个有物理依据的预设细节：

- `piano`：槌击点 L/8（压制 7/8 次分音）· 三弦同音弦组 0.9 音分失谐（拍频闪烁）· 双指数余韵 β=0.30 · 音板低频截止 85 Hz + 180/1400/3200 Hz 共振
- `violin`/`cello`/`erhu`：琴箱共振峰（A0≈275 Hz、B1≈450 Hz；二胡蛇皮 ≈300 Hz）+ 弓毛噪声 + 弓位 0.14
- `clarinet`：闭管 → 只有奇次分音，用激励点 `pos=0.5` 的梳状零点直接实现
- `bells`/`gong`/`marimba`/`vibraphone`/`timpani`：用**显式分音表**（钟 0.5:1:1.19:1.51:2.0…、马林巴 1:4:10、定音鼓 1:1.5:1.85:2.3），而不是拉伸谐波列
- `harp`/`bells`/`music_box`：`damper=0`（无制音器）→ 余音到能量 −60 dB 为止

单个乐器的完整参数（B/α/倾斜/τ1/n2/制音器/起音/稳态/激励点/弦组/共鸣体/分音表）用 `save --list` 查看；
或直接在 UI 的『插入面板 → 乐器预设』里选中后微调，再写入 `@timbre` 或 `@acoustic` 行。

旧式裸谐波音色（`piano`/`violin`/`flute` 的振幅表）仍可用 `-t` 指定，但与同名物理预设冲突时以物理预设为准。
### 旧式两行写法（deprecated）

```
120,261.63,0.5
1,0.7,0.5,0.3,0.2,0.1            ← 第 2 行: 谐波振幅
0-1!0-0.8!0-0.6!{0.1-0.3,0.5-0.7>}   ← 第 3 行: 持续比例
1.04 3.04 5.04
```

持续比例的时间窗按**音符时长比例**解释（这与"物理绝对时间"矛盾，故已不推荐）；`0-0` 表示该倍频全程不存在。新文件请改用 `@acoustic`。

| 指标 | 物理含义 | 合格标准 |
|---|---|---|
| 直流偏置 | 波形均值（直流分量） | `< 1e-4`（非 0 说明合成有 bug） |
| 峰均比 (crest) | 峰值/有效值 | 12 ~ 20 dB 较自然 |
| 真峰值 | 4 倍插值估计的样本间峰值 | ≤ 1.0（限幅后不会削波） |
| 响度 LUFS | 简化 BS.1770（K 加权 + 门限） | 用于跨谱子比较 / 发布一致性 |
| **硬切音块** | 音块首尾未淡到 0 的事件数 | **必须为 0**（硬切是咔哒的唯一来源） |
| 最大跳变 / 孤立跳变 | 相邻样本跳变及其与局部平均的比值 | 参考值：起音瞬态本身就会很大 |
| 分音上限裁剪 | 因 `maxp` 被裁掉的分音数 | >0 说明低音区带宽受限，可调大 `maxp=` |
| **发声长度** | 实际渲染时长（记谱时值 + 制音器 / 自然余音） | 与乐器的物理 τ 一致 |
| **T30** | 由 −5 dB 衰减到 −35 dB 的实测耗时 | 与模型 τ 同量级（< 15% 误差） |
| **分音数范围** | 参与合成的分音数（低音 vs 高音） | 低音多、高音少 |
| **实测重心/基频** | 渲染音频的频谱重心 ÷ 基频 | 应随音区变化（恒为常数 = 没有共鸣体） |
| **被截断事件** | 结束时仍在发声的事件数 | 0（每个音都按物理衰减完） |
| 对齐偏差 | 音符总长对拍号小节的偏差 | `< 0.02 s` 为对齐 |

## 插入面板（桌面端 UI）

菜单/按钮『插入面板』打开右侧停靠面板，用**勾选框 + 参数**的方式插入内容（安卓端有对等对话框，两端共用 `core/note_builder`）：

- **音符插入**：音级 / 变音 / 八度 / 拍长 / 附点 / 三连音 / 五连音 / 与前音连起来 / 力度（ppp~fff 或数值）/ 演奏法 / 重复次数 / 声部；
  和弦成员列表（『把当前音加入和弦』）；逐音物理覆盖（起音 / 衰减 / 稳态 / 亮度 / 非谐性 / 激励点 / 制音器，勾选才写入）；
  底部实时显示将要插入的 token，可『插入到光标处』『追加到文末』『复制』。
- **乐器预设**：33 种预设按分类列出（显示 τ₁ / 制音器 / 弦组 / 分音表等要点），选中后所有物理参数载入下方表单可微调；
  然后『应用 @timbre』写入简短乐器行，或『写入 @acoustic』把全部参数展开成一行（优先级更高，可覆盖文件内乐器）。

面板生成的文本一律由 `core/note_builder` 产生，`tools/test_physics` 会逐一断言它们能被严格解析、且 `@acoustic` 往返一致。

## 本轮物理模型重写（对比上一版 C++ 实现）

上一版把「物理」写成了教科书草图：固定 12 个分音、`br^(n-1)` 按分音序号衰减、
钟用拉伸谐波列，而且**在记谱时值处硬截断**——所以第 10 条声称的「包络改为绝对时间」
只在 `t < min(记谱时值)` 时成立。本轮按声学评审的 16 条结论全部重写（评审的可量化结论已并入下表，并由 `tools/test_physics` 固化成断言）：

| # | 上一版 | 本轮 | 实测差异 |
|---|---|---|---|
| 1 | 记谱时值处 cos² 硬截断，`hold_last_note` 只补静音 | 记谱时值 = 按键时长，松键后按 `damper`（齿毡阻尼）衰减；无制音器乐器按能量 −60 dB 定长 | 钟写 1 拍：0.5 s 处 −90 dB 静音 → **12.0 s 自然余音** |
| 2 | 分音数恒为 12 | `N = min(0.49·fs/f0, maxp)` | C2: 12 → **96**（谱顶 796 Hz → ≈6.9 kHz）；C6: 12 → 16 |
| 3 | `br^(n-1)` 按分音序号，重心严格 ∝ f0 | 频率域包络（tilt dB/oct + 共鸣体共振峰 + 低频滚降） | 重心/基频：恒为常数 **3.02**（C3=C4=C5）→ C3 **6.20** / C6 **3.10** |
| 4 | 力度只乘振幅 | 力度同时改音色（越重越亮/起音越硬/噪声越大） | 同音高 !pp 611 Hz ↔ !ff **1393 Hz**（旧：444.5 vs 444.4） |
| 5 | 无激励点 | `pos/posp` 梳状零点 | 钢琴 L/8 压制 7/8 次分音；单簧管 `pos=0.5` 得纯奇次分音 |
| 6 | 无共鸣体 | `body=f:Q:dB,…` + `hpf` | 小提琴 A0/B1、二胡蛇皮共振峰等 |
| 7 | B 为常数 | `B(f)=B·(f/261.63)^alpha` + `temp`/`stretch` | 低音 B≈1e-4、高音可达 1e-1，可做伸展调音 |
| 8 | `τ_n = damp/n^exp` 单参数、单指数 | `1/τ_n = 1/τ1 + n2(n²−1)` + 双指数余韵 `beta` | 钢琴「先快后慢」的余韵 |
| 9 | 起音噪声 = 未滤波白噪（同音高同种子） | 模态噪声（用同一组分音共振）+ 力度相关 | 音块首尾淡到 0，无硬切 |
| 10 | 钟/八音盒用拉伸谐波列 | `table=比率:振幅:τ` 显式分音表 | 钟 0.5:1:1.19:1.51:2.0…、马林巴 1:4:10、定音鼓 1:1.5:1.85:2.3 |
| 11 | 混响 RT60 固定、无预延迟 | `--reverb-rt60/-pre/-width/-damp` 参数化 | 环路增益由 RT60 反解 |
| 12 | `stereo`/`headroom`/`--duration-comp`/`@dyn` 是死开关 | 全部真正生效；新增 `pan/panpitch`、LUFS 归一 | `--duration-comp` 旧版输出 md5 与不加时相同 |
| 13 | 16-bit 向零截断、无 dither | 四舍五入 + TPDF dither，支持 24-bit | 消除量化谐波 |
| 14 | 体检指标是模型解析值（看不出「尾音被删」） | 实测 T30/重心/分音数/起音/硬切、LUFS、真峰值 | `--check` 能拦下硬切咔哒 |
| 15 | 8 种乐器 | **33 种**（含古筝/琵琶/扬琴/二胡/笛子） | `save --list` 按分类打印全部物理参数 |
| 16 | 提示词教 8 种乐器 | 提示词精简版（2053→1964 字符）加入 33 种乐器、物理要点、`@acoustic` 全键表、dB 力度语义 | `tools/check_prompt` 保证示例仍合法 |

新增的验收闸门 `tools/test_physics` 把这 16 条里可量化的部分做成断言（分音数、重心随音区、
力度音色、制音器余音、无硬切、声像展开、构造器可解析、`@acoustic` 往返），改坏任何一条都会 red。
## AI 生成提示词

提示词正文的**唯一来源**是 `core/ai_prompt.cpp`（`score_system_prompt()`），桌面端 `ui`（『复制提示词』按钮）与安卓端经 JNI 的 `getScorePrompt()` 都取这一份，不再两端各写一份而漂移。

提示词按**精简版**维护：只写模型必须知道的记法与物理要点（算法细节留在本文件），当前 42 行。

它教给模型的要点：

- **头部** `BPM,基准频率,标准拍长` 三值一行，强调『标准拍长必须精确等于 60/BPM』；`@meter` 拍号与『每行 = 1 小节、行内拍数之和 = 拍号』的铁律
- **乐器**：33 种预设按分类列出（键盘/拨弦/弓弦/管乐/打击/电声，含古筝/琵琶/扬琴/二胡/笛子），并点明物理特性：`damp` 是绝对秒数、记谱时值 = 按键时长、松键后按 `damper` 衰减、`damper=0` 的乐器自然余音、分音数随 f0 变化
- **`@acoustic` 全键表**（B/alpha/tilt/damp/n2/beta/atk/sus/damper/ring/noise/pos/posp/body/hpf/uni/detune/vtilt/pan/panpitch/stereo/temp/stretch/table）——一行列出，模型需要时才用
- **音值表**：分母→拍数换算（含 6/8 每行 3 拍）、附点、三连音 `4t`、五连音 `4q`
- **力度语义**：`!ppp..!fff` 对应 −24…+3 dB，并明确『**力度同时改变音色**：轻弹更暗更柔、重弹更亮更硬』，鼓励模型用力度塑造情绪；`@dyn` 可自定义力度表
- 连音 `_`（时值相加、只起音一次）、和弦 `[1.04,3.04,5.04]`（修饰符作用于整组）、逐音覆盖 `$dec/sus/atk/br/pos/damper`
### 提示词自检（改动后必跑）

```bash
./check_prompt          # 断言: 可解析 / 无警告 / 小节对齐 / 力度有起伏 / 无削波
```
